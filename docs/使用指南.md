## 推荐路径

1. 使用 `DI_CODE_PROVIDER=faux` 完成一次 `--print` 离线验证。
2. 选择一个真实 Provider，将 key 放进环境变量或 settings 的 `$ENV_VAR` 引用。
3. 需要持续对话时进入 `--interactive`；需要脚本消费事件时使用 `--mode json`。
4. 需要浏览器时运行 `di-code web`；需要自定义客户端时使用带 token 的 `di-code-webui`。

所有模式共享 Agent loop 和 SessionHost；模式差异只在呈现和传输层。文件工具、插件、MCP 和 shell 都应在可信工作区运行。
