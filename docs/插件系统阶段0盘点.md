# 插件系统阶段 0 盘点

本文记录 `@di-code/plugin-runtime` 落地前的旧插件实现边界与当前消费者。它是迁移参考，不描述新的可用插件 API；目标架构与后续阶段以[插件系统扩展实施方案](./插件系统扩展实施方案.md)为准。

## 冻结范围

以下旧实现从阶段 0 起只保留为行为基线，不新增功能；阶段 7 已删除旧 runtime，表格保留迁移历史：

| 旧实现 | 当前职责 | 当前生产消费者 |
| --- | --- | --- |
| `packages/coding-agent/src/extensions/types.ts` | 已删除的旧 `ExtensionAPI`、工具、命令和事件类型 | 仅迁移历史 |
| `packages/coding-agent/src/extensions/runtime.ts` | 已删除的旧 `ExtensionHost`、`.di-code/extensions/` 发现、注册和事件派发 | 仅迁移历史 |
| `packages/coding-agent/src/plugins/manifest.ts` | `plugin.json` 和 package `diCode.plugins` 的 manifest 校验 | `plugins/loader.ts`、`plugins/manager.ts` |
| `packages/coding-agent/src/plugins/loader.ts` | 项目与托管插件发现、导入及 `CodingAgentPluginHost` 注册 | `main.ts` |
| `packages/coding-agent/src/plugins/manager.ts` | 全局插件安装、启用状态与移除 | `main.ts` 的 `plugin` CLI 命令 |

旧 `.di-code/extensions/` 和旧 loader 已删除；当前 loader 只发现 `.di-code/plugins/` 与托管插件。

## 行为对照清单

| 能力 | 旧实现状态 | 新 runtime 阶段 | 阶段 0 状态 |
| --- | --- | --- | --- |

| 插件工具、命令和事件注册 | `ExtensionAPI`，无 disposer | 2 | 未迁移 |

| 项目 trust 与全局插件管理 | `coding-agent` 产品职责 | 3 接入 | 保持现状 |
