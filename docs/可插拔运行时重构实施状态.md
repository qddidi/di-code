### Public API

没有新增或修改公共 API。当前公共边界仍为：

- `@di-code/ai`：Provider-neutral `Provider`、`Model`、消息、工具 schema 和流事件；内建 OpenAI、Anthropic、DeepSeek、Kimi、Zhipu、Faux adapter 仍由该包导出。
- `@di-code/agent`：`Agent` 和唯一的 model-tool loop；coding-agent 负责工具实现、Session 和产品模式。
- `@di-code/coding-agent`：CLI `entry`、`AgentSession`、Session JSONL、`rpc` 子路径和旧插件/扩展 API。
- `@di-code/mcp`：MCP client/manager 生命周期、分页、取消和错误分类；不实现 Agent loop。
- `@di-code/orchestrator`：只通过 `@di-code/coding-agent/rpc` 公开协议监督子进程。
- `@di-code/tui`：presentation-only 的 ANSI terminal、TUI 和组件。

RPC 仍固定 `version: 1`、请求 `id`、事件 `requestId`，方法为 `prompt`、`cancel`、`get_state`。JSON mode 的事件版本仍为 `2`。

### Lifecycle/Security evidence

- 当前 Agent loop 的唯一执行者仍是 `@di-code/agent`；`AgentSession` 只组装工具并转发事件，RPC server 不实现第二套 loop。
- Session JSONL v2 追加、跨 manager lock、恢复诊断、branch context 和 compaction 语义已有测试；失败 append 不污染内存或后续队列。
- 文件工具使用 allowed-root canonicalization 并拒绝 parent traversal、外部绝对路径、外部/dangling symlink；bash 使用结构化 spawn 参数、明确 cwd、超时、取消和独立输出上限。
- 插件是同进程代码，不是沙箱；project trust 仅决定是否加载项目代码。manifest ID、entry root、权限声明、工具 namespace 冲突均校验，handler 诊断会脱敏 `token` 等凭据模式。
- MCP URL、headers、stdio command/args 由 MCP 包和宿主配置校验；连接失败只禁用对应 Server，并在结束时 close。
- RPC JSONL 校验版本、id/requestId、参数和事件；client 在子进程退出时拒绝 pending 请求，server 对并发 prompt 返回 `BUSY`，cancel 通过 AbortSignal 传播。
- TUI 测试覆盖 terminal startup failure 的状态回滚和 stop 幂等；orchestrator 只依赖公开 RPC SDK。

### Known risks

- 新 Runtime 尚未实现；上述目标 Registry/scope/entry 是迁移清单，不是当前可用 API。
- `main.ts`、`rpc-entry.ts`、`AgentSession` 仍直接 import/construct 生产实现，旧 `plugins`/`extensions` 双轨系统仍存在；这是后续阶段的主要耦合风险。
- coding-agent 的子进程测试必须执行源码入口或先构建；本阶段已消除对未提交 `dist` 的测试依赖，但发布产物仍需在后续 build/release gate 验证。
- 真实 Provider 网络行为未在无 key 环境验证；仅离线 Faux 和协议/适配器单测作为基线。
- RPC server 当前仍由 `rpc-entry.ts` 直接创建 Session；shutdown flush/dispose 顺序和 Registry method namespace 属于 Stage 12 风险。

### Next stage context

Stage 1 应只新增 `@di-code/plugin-runtime`、`@di-code/plugin-loader`、`@di-code/plugin-sdk` 的 workspace 和公共契约骨架：`PluginDefinition`、`Context`、`Fiber`、`ServiceKey`、`Disposer`、`PluginStatus`、`RuntimeEvent`、`RuntimeMode`、`ConfigSchema`、`PluginCapabilities`、Registry 基础类型及 namespace fixture。不得迁移 `main`、`AgentSession`、Provider、工具、Session、MCP、TUI 或 RPC 生产路径；继续保持本阶段基线测试绿色。
