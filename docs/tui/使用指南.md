# TUI 使用指南

`@di-code/tui` 是 presentation-only 的 ANSI 组件库，不读取 Provider、Session 或 coding-agent 配置。它适合在支持 TTY 的 Node.js 进程中嵌入，也可用虚拟终端测试。

## 最小程序

```ts
import { ProcessTerminal, Text, TUI } from "@di-code/tui";

const tui = new TUI(new ProcessTerminal());
tui.addChild(new Text("Hello from di-code TUI."));
tui.start();
process.once("SIGINT", () => tui.stop());
```

安装：`npm install @di-code/tui`。`ProcessTerminal` 默认使用 stdin/stdout；嵌入或测试时可传入替代流和 `env`。输出流没有尺寸信息时使用 `COLUMNS`、`LINES`。

## 组件模型

每个 `Component` 实现 `render(width): string[]` 和 `invalidate()`。把组件加入 `TUI` 或 `Container`；外部状态变化后调用 `requestRender()`。组件不应直接写 ANSI 控制序列，终端光标、清屏和输入由 `Terminal` 抽象统一处理。

主要组件：

| 组件 | 用途 |
| --- | --- |
| `Text`、`TruncatedText`、`Spacer`、`Box` | 基础布局和截断 |
| `Input` | 单行输入、mask、粘贴和取消 |
| `Editor` | 多行编辑、grapheme 光标、自动补全 |
| `Markdown` | Markdown 文本和代码块渲染 |
| `SelectionPanel`、`SelectList`、`SettingsList` | 键盘选择界面 |
| `Overlay` | 固定高度、遮罩和保留末行的面板 |
| `Autocomplete` | 异步建议、取消和提交 |

`TUI_THEMES`/`TuiTheme` 只描述 ANSI presentation colors；主题、Session、命令和工具审批属于产品层。扩展徽章、控制入口和审阅状态以只读 projection/facade 传入，TUI 不执行 Agent loop；窄终端会截断而不改变布局，组件应保持键盘焦点和可读状态。

## 输入和键位

`Input` 支持 Enter 提交、Esc/Ctrl+C 取消、左右/Home/End、退格/Delete 和 bracketed paste；可用 `mask` 隐藏 key。`Editor` 额外支持换行、上下移动、Unicode grapheme 边界、自动补全、`maxHeight` 和 `onCommand`。对于不发送 bracketed-paste 标记的 Windows 控制台，包含 CRLF 的多行剪贴板文本也会作为一次粘贴插入，不会逐行触发 Enter 提交。

产品 interactive 默认键位：Enter 发送、Shift+Enter 换行、Esc 取消、Ctrl+C 退出、Tab 补全、Alt+S steer、Alt+P 切换 Plan Mode、Shift+Tab 切换 thinking、Ctrl+O/L 打开模型/Session、Ctrl+T/S 主题/设置、Ctrl+R 重试。输入框底部第一行在模型左侧显示 `plan: off`、`plan: ON` 或 `plan: pending`。插件可注册自己的 `KeybindingsManager` 映射，但应避免覆盖核心取消和退出键。

## 自定义 Host

coding-agent 的 `createUiHostEntry()` 允许插件替换 interactive-host。Host 回调持续到 UI 退出，使用 `UiHost.session` 调用 prompt/cancel/retry/tree/compact，使用只读 `UiHost.product` 获取资源快照、主题、键位和脱敏诊断。必须监听 AbortSignal；退出、取消、异常和 composition dispose 都会等待 Session 操作结束并释放资源。

dispose 后 facade 失效，访问抛 `UiHostLifecycleError`（`DISPOSED`）。Session 操作错误以 `BUSY`、`INVALID_INPUT`、`NOT_FOUND`、`SESSION_IN_USE` 等稳定 code 表示。自定义 Host 与插件同进程运行，manifest permissions 不是沙箱。

## 测试

使用 `packages/tui/test/virtual-terminal.ts` 或 `emulated-terminal.ts` 渲染固定宽高，断言 ANSI 输出、光标位置、换行、焦点、Overlay 截断和取消行为。窄终端应保持稳定宽度，不让动态文本改变布局；中文和宽字符使用库的 `visibleWidth` 等工具计算。
