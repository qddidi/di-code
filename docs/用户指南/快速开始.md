# 快速开始

## 环境

需要 Node.js `>=22.19.0` 和 npm。源码运行前安装依赖：

```powershell
npm install --ignore-scripts
```

已发布版本可安装：

```powershell
npm install -g @di-code/coding-agent
di-code
```

## 不联网体验

Faux Provider 不读取网络或密钥，适合验证 CLI、Session 和工具循环：

```powershell
$env:DI_CODE_PROVIDER = "faux"
npm run dev -- --print "用一句话介绍这个项目"
```

`--print` 只输出最终 assistant 文本；错误写入 stderr。交互终端使用：

```powershell
$env:DI_CODE_PROVIDER = "faux"
npm run dev -- --interactive
```

## 首次配置向导

在真实 TTY 中直接运行 `di-code` 或 `npm run dev`，且没有 `DI_CODE_PROVIDER`、`defaultProvider` 或唯一已配置 Provider 时，会显示向导。向导选择 Provider、模型并隐藏输入 API key。选择 `Faux (offline)` 不需要凭据；选择 `Custom` 还要填写 API 协议、Base URL 和模型 ID。

向导**可以并且会**把本次选择写入用户级 `~/.di-code/settings.json`，包括默认 Provider、默认模型和（使用真实 Provider 时）API key。下次启动会直接复用这些设置，不需要重复输入。输入的 key 不会写入项目 settings、`.env`、Session 或日志；仍建议只在个人用户目录保存，并限制文件访问权限。`--print`、JSON、CI 和 non-TTY 不会启动向导，必须预先配置 Provider。

## 直接启动 WebUI

如果希望直接使用浏览器界面，不需要先进入 interactive TUI。已安装发布包时运行：

```powershell
di-code web
```

终端会输出本地地址，例如 `http://127.0.0.1:4312`，在浏览器打开即可。默认只绑定本机回环地址；可用 `--port` 指定端口，也可以用 `--workspace <path>` 添加已信任的工作区：

```powershell
di-code web --port 4312 --workspace D:\projects\another-workspace
```

从仓库源码启动对应命令：

```powershell
npm run build
npm run dev -- web
```

首次打开 WebUI 时，如果没有可用的真实 Provider，页面会先使用离线 Faux runtime；在 Settings 中完成 Provider 登录后，再开始真实请求。浏览器只接收脱敏配置和不透明 ID，不会获得 API key。

如果要启动给自定义客户端使用的 HTTP/SSE WebUI 入口，而不是内置浏览器页面，请使用 `di-code-webui`。它必须设置至少 32 个字符的 token：

```powershell
$env:DI_CODE_PROVIDER = "faux"
$env:DI_CODE_WEBUI_PORT = "8787"
$env:DI_CODE_WEBUI_TOKEN = "replace-with-a-random-token-of-at-least-32-characters"
di-code-webui
```

该入口默认也只绑定 `127.0.0.1`，token 只能通过 `Authorization: Bearer ...` 或 `X-Di-Code-Token` 请求头发送。需要远程绑定时还必须显式设置 `DI_CODE_WEBUI_ALLOW_REMOTE=1`，并配置可信 Origin。完整路由、SSE 恢复和客户端示例见 [WebUI 使用指南](../webui/使用指南.md)。

## 第一次真实请求

如果前面的向导或 Web 页面 Settings 已经配置好 Provider，

直接运行：

```powershell
npm run dev -- --print "检查当前项目的主要模块"
```

其他内建 Provider 的变量见 [CLI 与配置](CLI与配置.md)。

## 选择工作模式

| 模式 | 用途 | 入口 |
| --- | --- | --- |
| `print` | 单次请求、脚本 | `di-code --print "..."` |
| `json` | 消费版本化 JSONL 事件 | `di-code --mode json "..."` |
| `interactive` | 持续对话、工具状态和取消 | `di-code --interactive` |
| Web | 浏览器应用 | `di-code web` |
| RPC | 其他 Node 宿主监管 Agent | `di-code-rpc` |

模式不能随意组合：`--print` 不能与 JSON/interactive 同用，`--continue` 不能与 `--session` 同用，非交互模式必须提供 prompt。
